# Quintessential

Quality-of-life for Minecraft Beta 1.7.3: friends and messages, skins, and
hosting a world from the pause menu. It ships as a Java agent, so your game
files are never modified and uninstalling is one argument away.

**Download and install instructions:** Modrinth page link goes here.

## Reporting a bug

[Open an issue](https://github.com/KamalZakiiii/Quintessential/issues/new/choose) and
include:

- the log, or at least every line starting with `[Quintessential]` plus the
  error around it
- your launcher and `java -version`
- whether it happens in singleplayer, while hosting, or while joining

## Suggestions

Ideas go in [Discussions → Ideas](https://github.com/KamalZakiiii/Quintessential/discussions).
Questions and launcher setup go in the same place. Issues are for things that
are actually broken.

## What's in this repository

Issue templates and documentation only. The build workspace and the compiled
jar are not published here. Quintessential contains no Minecraft code or assets;
the Beta 1.7.3 server jar used while hosting is downloaded from the public
BetaCraft archive at runtime and checked against a known SHA-1.
